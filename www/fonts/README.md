# Press Start 2P

`PressStart2P-Regular.woff2` is bundled locally so the game does not depend on Google Fonts at runtime.

- Source: [Google Fonts — Press Start 2P](https://github.com/google/fonts/tree/main/ofl/pressstart2p)
- Original file: `PressStart2P-Regular.ttf`
- Original SHA-256: `034c77f1f05ec89421e4a63f0e3a4ca1ecf852cc6d2bf611f126f275728e017d`
- WOFF2 SHA-256: `ec0a835d8047efb59e51434c40cce52997d5dd235a0968f611b286c5f6fce743`
- License: SIL Open Font License 1.1; see `OFL.txt`.

The WOFF2 file was losslessly compressed from the official TTF with FontTools 4.60.1. It retains the full font character set, including the Cyrillic glyphs used by the Russian localization.
